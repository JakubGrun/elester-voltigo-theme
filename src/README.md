# Voltigo Theme

Applies Elester Voltigo's design system colors and branding to self-hosted Grafana instances.

## Overview

Voltigo Theme is a lightweight app plugin that restyles the Grafana UI to match Elester Voltigo's brand: dark background, purple accent color, and the Voltigo logo placed next to the dashboard controls. It works by injecting a stylesheet at runtime, so it requires no per-dashboard configuration.

## Requirements

- A self-hosted Grafana instance running version 12.3.0 or later.

## Getting Started

1. Install the plugin and restart Grafana.
2. Enable it under **Administration > Plugins**.

The theme applies automatically across the whole instance — there is nothing else to configure.
